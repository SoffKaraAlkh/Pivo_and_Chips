# Pivo_and_Chips
Локальный мультиплеер 2д платформер. Кооператив на общем экране <br>
Милая(наверное) Жизненная(точно) <br>
А еще мы питон. Хз почему. Бог так сказал <br>
Работаем с помощью библиотеки Pygame <br>
В прохладном сумраке супермаркета встретились две родственные души: отважная бутылка Пива и хрупкая упаковка Чипсов. Он катился, сверкая золотистыми боками, она нежно шуршала рядом. Вместе они преодолевали лабиринты стеллажей, уворачивались от гигантских тележек. Он остужал её тревоги каплями влаги, она дарила ему тепло и силу. Их путешествие к сияющему выходу стало идеальным танцем — хрустящим и прохладным, как сама любовь.
